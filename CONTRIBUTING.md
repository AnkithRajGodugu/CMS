# Contributing

Thank you for considering contributing to this project!
**Team scratch coders**
## How to Contribute

## Code of Conduct
Please be respectful and follow the code of conduct in all interactions.
## Commit Guidelines
- Write clear, descriptive commit messages summarizing your changes.
- Reference related issues or pull requests when applicable.
- Group related changes into a single commit when possible.

## Pull Request Process
- Ensure your branch is up to date with the main branch before submitting a PR.
- Provide a summary of your changes and the motivation behind them.
- Tag reviewers and request feedback if needed.
- Address review comments promptly.
